# Recipe Saver
Recipe Saver is a web application to keep track of recipes and easily find and save new recipes from an API.

## Features
- Add, edit, and delete recipes
- A rich text editor to format details 
- Pin recipes to quickly find favorites
- Upload an image 
- Search and save from Edamam's recipe database
- User authentication with Google sign-in

## Built With
- Frontend: React, JavaScript, CSS
- Backend: Node.js, Express.js
- Database & Authentication: Firebase
- Deployment: Vercel
